Resonant Scaling Theory (RST)
Independent, self-funded research framework on resonance and scaling, with Python simulation code and documentation.
Status: not peer-reviewed. This is an independent research project. Claims here are hypotheses and results from the project's own analyses, not established science.
What is RST?
RST uses spectral graph metrics (the Fiedler vector and algebraic connectivity, λ₂) to describe state transitions in networked systems. It started from EEG analysis and has been tested on EEG datasets and, as exploratory work, on network data from other fields.
