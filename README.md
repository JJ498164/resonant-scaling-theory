# Resonant Scaling Theory (RST)

Independent, self-funded research framework on resonance and
scaling, with Python simulation code and documentation.
Not peer-reviewed.

## What's in here
- docs/ : theory, math appendix, abstract
- src/ : current engine
- validation/ : tests and logs

## Status
Current version: v6.1
Fitted parameters (e.g. 8.79 Hz, 39 Hz) come from the project's
own datasets. They are not claimed as universal constants.
